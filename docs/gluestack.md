# gluestack-ui in the gallery (06-u15)

## Version and engine

- **gluestack-ui 3.0.12** (the `v3-stable` tag), pinned exactly as a dev dependency (the CLI).
- **Engine: NativeWind 4.2.7 on Tailwind CSS 3.4.19**, with react-native-web 0.21.2, `@gluestack-ui/core` 3.0.25, `@gluestack-ui/utils` 3.0.21 and `@gluestack/ui-next-adapter` 3.0.3. All pinned exactly (no ranges).
- **Why not 5.0.3 (npm `latest`)**: its own docs state that v5 does not support Next.js until NativeWind v5 adds web support; v5 targets Expo and React Native CLI only. The `4.x` line exists only as alphas. 3.0.12 is the newest stable that supports Next.js. Its docs list Next.js 13 to 15; it builds and exports cleanly on Next 16.3.8 (Turbopack) and React 19.2.8 here, which is the evidence for Next 16.
- react-native-web 0.19.13 (what the CLI writes) peers on React 18 and fails install on React 19, so 0.21.2 is used.
- This is a different engine family from `can_app` if that app takes gluestack v5 (NativeWind v5 or UniWind). Components are copied source, so nothing is shared at runtime. To be reported for DECISIONS.md.

## What was installed

Components, generated once by the CLI and now owned by the gallery (D-80): box, text, heading, link, button, divider, in `src/components/ui/**`. Do not regenerate over them.

Deviations from the CLI output:

- The CLI writes to `components/` at the repo root and rewrites `next.config.ts`, `layout.tsx` and `globals.css`. Components moved to `src/components/ui`; `next.config.ts` keeps `output: 'export'`, `trailingSlash` and unoptimized images, wrapped in `withGluestackUI`.
- **No global `jsxImportSource`.** NativeWind's JSX runtime added about 79 KB gz to every page. Instead each generated file has a `/** @jsxImportSource nativewind */` pragma, so only pages that import a component pay for it.
- **No Tailwind reset** (`preflight: false`) and no safelist, so existing pages look unchanged and unused colours cost no CSS. `darkMode: 'media'`.
- **Provider is a pass-through.** The generated provider injected the theme variables in a layout effect (a flash, and nothing without JavaScript). The theme is plain CSS variables in `src/app/globals.css`, switched by `prefers-color-scheme`. Overlay and toast providers were dropped until a component needs them.
- `nativewind-env.d.ts` is kept inside `src/components/ui/` (types for `className`).
- ESLint ignores `tailwind.config.js` and `postcss.config.js` (CommonJS).
- The CLI is interactive and needs a TTY; it was run under `script` with a throwaway HOME so the real `~/.gluestack` was not touched.

## Theme

Gallery-owned (D-80), from the OWN-WORLD block of `.impeccable/surfaces/src-app-page-tsx.md`: paper `#E9EEF2` (dark `#14181C`), ink `#1A1A1A` (dark `#E9EEF2`), primary cobalt `#1F4FA3`, secondary ochre `#C8902E`, tertiary green `#2F7D4F`, with lighter tints in dark mode (`#7FA3E6`, `#E0B25A`, `#6FBF8D`). Scales are generated by mixing towards white and black; error, success, warning, info and indicator variables keep the generated defaults. The synced `tokens.css` status hues are untouched and still drive chips. 16-u10 refines the scales and applies the identity.

## Static export

`output: 'export'` unchanged, no runtime fetch, no form, no cookie, no font. `check:out` is green.
