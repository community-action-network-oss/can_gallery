# Adding a language

The gallery ships English only, at unprefixed root paths (`/how-it-works/`). Everything below is how a second language is added later. None of it is done yet.

## What exists now

- `src/lib/locale.ts`: `LOCALES`, `DEFAULT_LOCALE`, a direction map and `htmlAttrs(locale)` (lang and dir). The root layout uses it.
- `src/lib/paths.ts`: `localePath(path, locale)`. Unprefixed for the default locale, `/{locale}{path}` otherwise. Every internal link goes through it.
- `npm run check:locale` fails on a literal internal `href="/..."` outside `paths.ts`, on a hard-coded `lang` in the layout, and when a listed route has no page.

## Steps to add a locale

1. Add the code to `LOCALES` and its direction (`ltr` or `rtl`) to `DIRECTION`.
2. Move the pages under `src/app/[locale]/` and add `generateStaticParams` returning `LOCALES`. Keep English reachable at the unprefixed paths (static hosting has no server redirects), for example by also emitting the default locale from the same pages.
3. Copy the English copy to `src/content/<locale>/` and translate it. Copy that must stay claim-checked (`docs/claims.md`) needs its own claim rows, because the claims check matches sentences verbatim.
4. Follow the translator rules in `docs/open-questions/OQ-unsupported-language.md`: plain words, no machine only translation published as final, and the same Planned labels.
5. Check right to left layout (logical CSS properties, mirrored icons) if the locale is rtl.
6. Add `hreflang` alternates for each page in its metadata, including `x-default` for English.
7. Pass `locale` to `localePath` wherever links are rendered, and add a language switcher only when two locales exist.

## Deliberately not done yet

- No `/en` prefix, no second locale, no language switcher, no translated text, no `hreflang` output.
- No pages under `[locale]`. Moving them is the first step of the first translation.
- Planned routes (`/archive-and-reuse`, `/private-location`, `/archive`, `/archive/[id]`) join the route list in `scripts/check-locale.mjs` when their pages land.
